# ICALIS 2027 — International Conference Landing Page
### Arabic Language and Globalization: Experiences, Visions, and Horizons
**المؤتمر الدولي: اللغة العربية والعالمية — تجارب ورؤى وآفاق**

Situs web resmi landing page untuk Konferensi Internasional yang diselenggarakan oleh:
- **Institut Agama Islam PERSIS Garut (IAI PERSIS Garut / جامعة برسيس)**, Indonesia
- **Yayasan Thaba untuk Pendidikan & Pelatihan (Taba Foundation / مؤسسة طابة)**, Kairo & Madinah

---

## 🌟 Fitur Utama
1. **Dukungan Penuh 3 Bahasa (Trilingual):**
   - Bahasa Indonesia (`id`)
   - Bahasa Arab (`ar`) — dilengkapi orientasi teks otomatis *Right-to-Left (RTL)*
   - Bahasa Inggris (`en`)
2. **Language Switcher Permanen:**
   - Tersedia di sticky header navigasi atas.
   - Tersedia di floating quick-action bar bawah (pada layar smartphone).
3. **Otomatisasi Biaya Sesuai Bahasa:**
   - Bahasa Indonesia → Otomatis menampilkan tarif Rupiah (IDR).
   - Bahasa Arab / Inggris → Otomatis menampilkan tarif Dolar / Riyal (USD / SAR).
4. **Jurnal Ilmiah Afiliasi Terakreditasi SINTA & ISSN:**
   - **Al-Bayan** (SINTA 2) — E-ISSN: 2528-1054
   - **Al-Muyassar** (SINTA 2) — E-ISSN: 2829-095X
   - **Mantiqu Tayr** (SINTA 3) — E-ISSN: 2774-6372
   - **Arabia** (SINTA 4, UIN Sunan Kudus) — P-ISSN: 2085-644X, E-ISSN: 2502-2482
5. **Jalur Registrasi Tunggal Terverifikasi:**
   - Terintegrasi langsung ke Google Form Resmi: `https://forms.gle/PpKqKkbv25GvpAzx5`
6. **Buku Panduan Konferensi (PDF):**
   - Modul booklet PDF resmi dapat diakses langsung pada `assets/booklet-konferensi.pdf`.
7. **Mobile-First & Responsif Penuh:**
   - Dioptimasi untuk berbagai ukuran layar (iPhone, Android, tablet, desktop).

## 🚀 Cara Menjalankan
Halaman ini berupa web statis modern (HTML5, Tailwind CSS via CDN, Font Awesome, dan Google Fonts).
